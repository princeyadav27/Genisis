# Genesis
A causal society simulator with an AI cognition layer.

## Contract
The deterministic engine alone changes authoritative state. Narrative never produces resources. 20 individually modeled residents; seed 42; logical 64×64 island. Offline mock planning. Explicit movement, needs, production inputs/outputs, memories and events. No offline progress. Pause invalidates the generation. Save/load preserves tasks and restores paused.

## Session scope
A runnable Living Village vertical slice, not the entirety of Release A. Build live isometric rendering, selection, camera controls, individual needs/tasks, food/water gathering, resource transport, material-backed construction, recorded conversations, event inspection, resource dashboards, ten read-only supervisory summaries, pause/step/stop/save/load.

## Deferred release requirements
Full negotiations/contracts, inventory-backed market, households changing, maintenance, optional LLM adapter, subjective belief propagation, full supervisor proposal contracts, advanced seasons and ecology. Release B generations/institutions and Release C visitors/expansion are not implemented.
